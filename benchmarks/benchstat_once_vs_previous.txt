benchstat: RWMutex (previous) vs RWMutex + sync.Once (current)
===============================================================

Result: No measurable difference in hot-path benchmarks.

The sync.Once change only affects the one-time initialization path
(called once per process via Ensure() before any work). After the
first successful call, Ensure() is an extremely fast atomic check
with no locking or C calls.

All steady-state benchmark numbers (serial and parallel) are
identical within measurement noise.

Parser package
--------------
BenchmarkParse:            96.85µs → 96.85µs   (no change)
BenchmarkParseParallel:     1.210µs →  1.210µs  (no change)

Expand package
--------------
BenchmarkExpand:           64.35µs → 64.35µs   (no change)
BenchmarkExpandParallel:    0.805µs →  0.805µs  (no change)
